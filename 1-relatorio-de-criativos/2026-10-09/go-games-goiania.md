- Fonte: Meta Ads via MCP, `date_preset: last_7d`. A API não devolve as datas; o período `02/10 a 08/10` foi inferido (7 dias terminando ontem, relatório gerado em 09/10/2026).

- Critério do Top 4: custo por resultado, só criativos com resultado; quem investiu menos de R$ 20 só entra para completar as 4 vagas e fica marcado como volume baixo (leitura direcional). Criativos com o mesmo nome em conjuntos diferentes aparecem uma vez (melhor instância).

A API devolve `&amp;` dentro da URL; no relatório foi convertido para `&` (mesma URL, funciona no WhatsApp).
